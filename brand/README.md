# Ayu: logo

The crescent moon with four-point stars and dots. Use these files by their stable links:

```
https://raw.githubusercontent.com/mxxnpy/mxxnpy/main/brand/<file>
```

| File | Background | Use it for |
| --- | --- | --- |
| `ayu-moon-clear.svg` | transparent, cream mark | anything already dark |
| `ayu-moon-night.svg` | night `#0B0D17` | avatar, social images, dark pages |
| `ayu-moon-paper.svg` | paper `#F7F5EF`, ink mark | light pages, print |
| `ayu-moon-name-{clear,night,paper}.svg` | same three | the mark with "ayu" on the inner curve, 200 px and up |
| `ayu-moon-96-{clear,night,paper}.svg` | same three | headers, cards |
| `ayu-moon-32-{clear,night,paper}.svg` | same three | small icons (two stars) |
| `ayu-moon-16-{clear,night,paper}.svg` | same three | favicon (one star) |

## Colours

| Role | Hex |
| --- | --- |
| Moon on dark | `#F7F2E6` |
| Moon on light | `#1C1E2A` |
| Night | `#0B0D17` |
| Paper | `#F7F5EF` |

## Rules
- Do not redraw, recolour or rearrange the crescent, stars or dots.
- No slogan next to the mark.
- Below 200 px, use the version without the name.
- Each element has an id (`moon`, `star-1…6`, `dot-1…5`), so it can be animated on its own. Keep the motion gentle, and turn it off when the visitor prefers reduced motion.
